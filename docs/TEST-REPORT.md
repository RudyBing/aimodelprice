## 已知问题

### 1. RSS 源访问问题
**现象**: 部分 RSS 源抓取失败（404, 403, 超时）

**原因**: 
- 网站反爬机制
- 网络访问限制
- RSS 地址变更

**影响**: 较小，有其他源补充

**解决方案**: 
- 定期更新 RSS 源地址
- 考虑使用代理服务
- 增加更多备选源

### 2. NewsAPI 未配置
**现象**: API 抓取被跳过

**原因**: 未设置 NEWSAPI_KEY 环境变量

**影响**: 中等，新闻来源减少

**解决方案**: 
- 在 .env 文件中配置 NEWSAPI_KEY
- 或完全依赖 RSS 源
